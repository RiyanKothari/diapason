Tests: planted bugs

Each bug has a targeted call. Caught = flagged on v1 with evidence. "v2 also flagged" = the same flag on v2: Evon plays v2 and can genuinely slip, so read the quote to tell a real v2 failure from a false alarm. v1 pass rate 0% → v2 0%. Reports: v1 · v2 · v1 + Guard · v3 (secrets isolated) · v3 + Guard · v4 (acts + Guard)

Bhool Guard checks every line v1 is about to speak (banned threats, secret requests, account details before the caller proves the account's last 4 digits, the recording disclosure) and rewrites it in code before text-to-speech (about 1 ms per line measured live). VAD and barge-in bugs are audio engineering and stay v1's. v3 is v2 with the secret taken out of the model: code checks the caller's digits, and the amount and due date reach the model only after that; the verification digits never do. A model can't leak what it was never given.
